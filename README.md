# MyKOS Web — Landing Page Oficial

Sitio web oficial de presentación del **Ecosistema MyKOS**, la plataforma personal de inteligencia artificial con pasarela multimodelo, motor de voz bidireccional y suite de aplicaciones de escritorio para Linux y Windows.

🌐 **Demo en vivo**: [https://eskib0.github.io/mykos-web/](https://eskib0.github.io/mykos-web/)

---

## 🚀 Características del Sitio

- **Diseño Moderno & Responsivo**: Estética cyberpunk/terminal construida con React 18, Tailwind CSS v4 y animaciones suaves.
- **Bilingüe (Español 🇪🇸 / English 🇬🇧)**: Selector dinámico de idioma con traducciones completas.
- **Showcase Completo**:
  - Resumen del gateway y métricas del ecosistema.
  - Arquitectura separada (Gateway Node.js + Worker Python).
  - Proveedores de IA compatibles (Claude, OpenAI, Gemini, Meta AI, Strata, Ollama, etc.).
  - Motor de voz local y en la nube (Whisper, Chatterbox, Kokoro).
  - Suite de aplicaciones de escritorio ([MyKOS-Whats](https://github.com/eskib0/mykos-whats), Monitor GTK4, Analizador de disco PySide6).
  - Guía rápida de comandos CLI.
  - Instalador interactivo con pestañas para Linux y Windows.

---

## 🛠️ Tecnologías

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Empaquetador**: [Vite](https://vitejs.dev/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconos**: [Lucide React](https://lucide.dev/)
- **Despliegue**: GitHub Pages (GitHub Actions automatizado)

## 💻 Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```
